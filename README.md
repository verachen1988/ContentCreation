# ContentCreation

做自媒体账号内容生成的尝试

## 📚 文档

- [技术栈文档](./TECH_STACK.md) - 详细的技术栈和架构设计说明

## 🚀 快速开始

本项目使用 Next.js 14+ (App Router) 构建，基于 React 18+ 和 TypeScript。

### 主要功能

- 🎤 音频转写（Deepgram）
- 🤖 AI 内容总结（DeepSeek）
- 👤 用户认证（Supabase Auth + Google OAuth）
- 💾 云存储（Cloudflare R2）
- 🌍 多语言支持（40+ 语言）

### 技术栈

- **前端**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **UI 组件**: shadcn/ui, Radix UI, Lucide React
- **认证**: Supabase Auth
- **数据库**: Supabase (PostgreSQL)
- **存储**: Cloudflare R2
- **AI 服务**: Deepgram, DeepSeek

查看 [技术栈文档](./TECH_STACK.md) 了解更多详情。
